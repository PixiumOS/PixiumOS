# Security Policy

## Supported Versions
PixiumOS is currently in early development (Alpha). Security updates are provided for the latest codebase only.

## Reporting a Vulnerability
**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them directly to the project maintainer via private message on Telegram or Discord (links in README). 

We will try to respond within 48 hours and will keep you updated on the fix.
